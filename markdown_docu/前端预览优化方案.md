# 前端预览图片优化方案（简化版）

## 1. 现状分析

### 受影响的节点
- `InteractivePerspectiveMixer` (nodes.py)
- `InteractivePerspectiveMixerAdvanced` (nodes_advanced.py)

### 当前行为
每次节点执行都会保存 **3 张 PNG 图片** 到临时目录供前端预览：

```python
# 三张图片
result_save = _save(result_u8[:, :, :3], "r")    # 合成结果
bg_save = _save(bg_np, "b")                       # 背景输入
layer_save = _save(layer_np, "l")                 # 图层输入

# 保存时使用低压缩级别
pil_img.save(os.path.join(tmpdir, name), compress_level=1)
```

### 问题
- 磁盘 I/O 压力大：单次执行 9-15MB（1080p RGB）
- 10 个节点工作流 = 90-150MB per run
- 批量处理 / 长期队列运行导致 `temp` 目录爆满

---

## 2. 修改方案

### 2.1 添加简单开关参数

在两个节点的 `INPUT_TYPES` 中的 `optional` 字段添加：

```python
"save_preview": ("BOOLEAN", {
    "default": False,
    "tooltip": "开启则保存3张预览图 (结果+背景+图层) 用于 Open Editor；关闭则不保存任何预览（节省磁盘）",
}),
```

### 2.2 参数行为

| 状态 | 保存文件 | 用途 | 空间消耗 |
|------|--------|------|--------|
| `True` (开启) | 3 张 | 需要 Open Editor 调整坐标，或前端预览 | 9-15MB（1080p） |
| `False` (关闭) | 0 张 | 批量生成、队列处理、仅需输出结果 | 0MB |

### 修改 `apply_perspective()` 或 `apply_perspective_advanced()` 方法

## 5. 向后兼容性

- **默认值** `save_preview=False`（**关闭**）
  - 新方案默认不保存预览，符合大多数批量处理场景
  
- **现有工作流**
  - 若要继续看预览，需手动打开 `save_preview=True`
  - 或在需要 Open Editor 时临时启用

---

## 6. 使用建议

### 何时打开 `save_preview=True`
- 首次调试工作流，需要用 Open Editor 调整角点
- 需要在前端看预览缩略图
- 进度反馈时使用

### 何时保持 `save_preview=False`（推荐默认）
- 批量生成任务
- 队列处理
- 仅关心最终输出结果
- 需要保护磁盘空间

---

## 7. 应用到两个节点

### 修改文件
1. **nodes.py** - `InteractivePerspectiveMixer` 类
   - `INPUT_TYPES` 添加 `save_preview` 参数
   - `apply_perspective()` 方法添加条件判断

2. **nodes_advanced.py** - `InteractivePerspectiveMixerAdvanced` 类
   - `INPUT_TYPES` 添加 `save_preview` 参数
   - `apply_perspective_advanced()` 方法添加条件判断

---

## 8. 前端 Open Editor 兼容性

✅ **不受影响**

- Open Editor 优先从上游节点（如 LoadImage）直接加载图片
- 仅在上游不可用时才回退到 `node.imgs` 缓存
- 标准工作流推荐：使用 LoadImage 提供背景和图层
- 此时即使 `save_preview=False`，编辑器仍能正常加载显示

---

## 9. 总结

| 项目 | 说明 |
|-----|------|
| **参数** | `save_preview`（BOOLEAN） |
| **默认值** | `False`（关闭，不保存预览） |
| **开启时** | 保存 3 张 PNG，用于前端预览和 Open Editor |
| **关闭时** | 不保存任何文件，节省 100% 磁盘空间 |
| **兼容性** | Open Editor 仍可正常工作（优先从上游源加载） |
| **适用场景** | 两个 IPM 节点（基础版和高级版） |
